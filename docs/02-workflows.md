# 两条闭环工作流

更新：2026-09-29 · 映序 v1.2。具体按钮见 [漫剧手册](04-drama-manual.md) 与 [美女手册](05-beauty-manual.md)。

工作台负责剧本、提示词、参考输入、候选筛选和交付；公开 AI 平台生成图片、视频与配音，外部工具完成剪辑发布。本地单人使用，不要求接入生成 API。

## 工作空间与项目

工作空间提供共享人物、来源、模板、模型档案、配方、连接设置和回收站。项目承载镜头、单条作品、生成尝试与交付。跨项目导入复制内容及媒体快照，双方后续独立修改。

项目首页为行动中心，展示待设置的当前版本、待筛选候选、上游变化与交付缺项。侧栏只保留主流程入口；实体编辑、版本和历史在对应节点就地展开。

## 漫剧六步

| 步骤 | 产物与操作 | 完成条件 |
|---|---|---|
| 编写剧本 | 导入小说、漫画页或段子，选择范围后由 M00 改编；也可手写 | 当前集有明确的当前剧本 |
| 剧本分镜 | M01 拆镜，提取人物、场景、道具 | 镜头有画面目标、顺序与时长，并设为当前版本 |
| 文字生图 | M02 或逐镜写图片词，外部出图，批量回填 | 每个必需镜头选定当前图片 |
| 图生视频 | 绑定当前首帧，M03 或逐镜写视频词 | 每个必需镜头选定实际视频 |
| 人声配音 | 外部音轨、音色备注、逐句时间、试听 | 有配音与台词时间，或明确标记无配音 |
| 导出 | 检查当前集全部版本与依赖 | 缺项与过期引用处理完毕 |

分镜以稳定镜号关联上游剧本。`order` 决定排列顺序，`duration` 为目标剪辑秒数，`dialogue` 保存对白。人物稳定身份与服装状态分别描述，跨镜使用实际参考图；文字本身不能保证人物一致性。

剧本来源按 `novel`、`comic`、`joke` 或 `other` 记录。小说保留因果并把叙述转成可拍内容；漫画按页序和人工校对描述处理，只有明确勾选的页面图片才发送给视觉模型；段子保留铺垫、反转和包袱，只补最少的场景衔接。

视频默认一镜一个主要动作。首尾帧、动作驱动、负面词等能力以实际平台或工作流档案为准，不能按模型名猜测参数和输入槽。

## 美女四步

| 步骤 | 产物与操作 | 完成条件 |
|---|---|---|
| 选择人物 | 新建带参考图的人物或从共享库导入 | 人物及当前作品已确认 |
| 选择今日主题 | 日常、穿搭、舞蹈模板或自定义想法 | 主题、画幅、时长明确 |
| 生成视频 | 直接提示词、参考视频或图生视频 | 候选中选定实际当前视频 |
| 导出 | 视频、封面、提示词和参考记录 | 检查通过 |

需要首帧的平台在“生成视频”内完成图片准备。直接提示词路线不强制出图。参考视频路线需选择实际视频、标注观察时间范围并确认目标平台的输入能力。关键帧不能替代完整动作、音轨或精确卡点分析。

历史图片作品继续保留，新流程以视频为交付结果。沿用人物或套用主题模板创建新作品，不复制旧作品的完成状态。

## 高频生产闭环

**复制当前提示词 → 外部生成 → 素材箱批量关联 → 必要时筛选候选 → 局部返修 / 设为当前 → 交付。**

素材箱每批最多 200 个文件。完整镜号和可选版本号用于自动匹配；按文件修改时间和每镜候选数也能顺序分配。所有匹配在确认前可修改。上传前已经筛好且每镜只有一个结果时，可直接设为当前并跳过候选筛选；同镜多个结果必须保留为候选后再选择。实际改过提示词或参数时记录实际值，不能把成功归因给未使用的版本。

候选图片/视频筛选采用 J/K、左右键切换，A 设为当前结果、R 返修、X 淘汰。只有返修需要意见；淘汰仅改变判定，原文件与输入保留。对比同镜 2–4 个候选，突出实际提示词、模型、参数和输入差异。胜出结果一键保存配方，注明单样本验证边界。

## 版本、删除与交付

保存草稿创建修订，不改变下游引用。设为当前版本才移动当前版本指针。进入下一步前检查上游，列出将使用的当前版本、更新时间和缺项。

上游变化后，受影响的下游需复核；冻结的历史输入不随更新自我失效。旧候选复核时保留原 `prompt_ref` 和实际用词，单独记录此次检查针对的当前版本。

删除进入回收站，至少保留 30 天且不自动清理。恢复保留原 ID 与媒体，永久清空需用户主动操作并核对影响范围。

交付按当前集或单作品范围打包，包含已选视频、配音、SRT、提示词和素材清单。工程备份包含完整历史和回收站，恢复创建新项目。两种 ZIP 均不包含模型连接密钥。
