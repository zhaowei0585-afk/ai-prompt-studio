# 工作台产品与技术说明

更新：2026-09-29 · v1.2

## 产品路径

漫剧六步：编写剧本、剧本分镜、文字生图、图生视频、人声配音、导出。

美女四步：选择人物、选择今日主题、生成视频、导出。首帧准备位于视频节点内，支持直接提示词、参考视频和图生视频三条路线。

默认界面为顶部阶段导航、当前工作区与底部下一步按钮。图片/视频节点集中提示词、批量素材箱、候选预览和返修。动作中心处理缺项；实体历史、版本和可选参数作为详情保留。

工作空间共享人物、来源、模板、模型档案与配方。跨项目复制素材与当前版本，不进行隐式同步。

## 实现边界

Python 标准库 HTTP、SQLite、本地媒体文件和原生 JavaScript/CSS。无需安装运行时依赖、构建前端、运行 GPU 模型。服务仅监听本机。

文本/视觉模型仅生成提示词或结构化草稿，媒体在外部平台生成，配音先支持外部音轨导入。没有生成平台全量直连、实时多人协作、自动 OCR、自动切镜、完整视频理解或在线剪辑。

## 版本与并发

Entity 保存 `head` 与 `accepted`，Revision 保存 `content`、明确版本的 `deps`、元数据和创建时间。

- “保存草稿”仅新增 Revision。
- “保存并设为当前版本”在同一事务中创建修订和更新 `accepted`。
- `base_revision` 防止覆盖其他窗口的新编辑；`expected_accepted` 防止改写已变化的当前指针。
- 依赖引用具体版本，`frozen` 保留用于返修的历史输入，避免自身更新形成假过期。
- 阶段批量同步是单事务，校验所有 ID、镜长和素材引用，保留用户真实素材绑定。

`shot` 兼容漫剧镜头与美女单作品。`attempt.medium` 和选择事件分别区分图片、视频。`prompt_ref` 始终保留实际生成来源；重新检查旧结果可记录 `reviewed_against`，不重写实际输入。

## 批量与判片

上传文件保存在项目素材中；用户核对映射后，`batch-attempts` 一次创建 1–200 个待检查结果。稳定 ID 由媒体 ID、提示词版本及类型派生，同一批次重试不重复创建候选。

`review` 在同一事务中写入判定修订与当前选择事件。状态为 `unreviewed`、`accepted`、`rejected`、`discarded`；淘汰不删除媒体，撤销当前结果有独立事件。

对比支持同镜 2–4 个候选，显示实际提示词、平台/模型、参数与输入差异。文本高亮用于辅助比较，不替代完整输入快照。

## 配音与交付

`voice` 关联明确镜头版本，保存 `no_voice`、音频 ID、音色/情绪/语速备注及台词行。每行含说话人、文本和相对本镜的起止秒数，保存时校验音频类型和时间边界。

`production` 返回阶段缺项、引用版本、更新时间与是否可交付。页面下一步及交付按钮使用该检查。兼容旧 M01/D03 剧本及明确绑定的旧首帧。

页面交付采用 `handoff?episode=...&work=...&checked=1`，服务端再次校验；按范围打包当前结果、参考输入、提示词、镜头表、配音 JSON 和整集 SRT。未加 `checked=1` 的历史 API 仍可导出带缺项的草稿交接，用于兼容旧调用。

## 回收站与备份

`trash` 保存逻辑删除标记、原目标、删除时间与 30 天保留时间。不会按时间自动清空。恢复保留原 ID、修订与媒体。

只有主动永久清空项目才移除项目媒体目录。单个记录永久清空前复查历史引用，仍被引用则拒绝。文件移除与数据库写入沿用事务和目录暂存，失败时回滚。

备份保持 schema 1，并添加可选 `trash` 列表；旧备份无需该字段。恢复校验 ID、版本、媒体路径、SHA-256 与依赖完整性，并创建独立项目。

## 模型与本地数据

配置保存到项目外的私有设置文件。连接测试使用最小文本或单图请求，结果绑定配置签名并记录时间；修改连接后旧测试失效。失败信息不回显密钥或供应商响应正文。

图片选择阶段前置检查视觉配置，正式调用仍展示完整发送预览。测试通过仅表明接口接受该请求，不代表完整视觉能力或媒体质量。

## 验证

- `checks/smoke.py`：访问限制、并发版本、依赖、媒体范围读取、生成快照、错误草稿、备份与路径校验。
- `checks/production.py`：30 镜 × 4 候选、幂等回填、冲突、配音/SRT、范围交付、回收站恢复及跨项目媒体复制。
- `checks/browser.py`：隔离项目中实际上传 120 个图片候选，键盘判片、对比、30 条视频回填、六步/四步流程及移动端布局。

验证使用临时工程、模拟模型与测试媒体，不证明真实生成质量，也不访问个人密钥。真实创作者任务观察和目标生成平台实测应单独开展。
