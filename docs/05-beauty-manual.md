# AI 美女使用说明书

更新：2026-09-29 · 映序 v1.2

**选择人物 → 选择今日主题 → 生成视频 → 导出。**

图片准备位于生成视频节点内部。直接提示词路线不强制生成首帧。

## 1. 选择人物

在 AI 美女 Tab 创建项目，进入生产流程。

从当前项目选择人物，或点击“新建人物”，填写稳定特征并导入清楚的参考图，保存并设为当前版本。没有图时，可以在人物详情写参考图提示词，到外部平台生成后再导入。

点击“打开共享人物库”，可从漫剧或其他人物项目复制已有角色及媒体。复制后双方独立修改。

选好人物，保存并设为当前版本，再进入主题。

## 2. 选择今日主题

日常、穿搭、舞蹈是主题卡片。填写作品名称、今日想法、平台、画幅和时长。

例如：“咖啡店窗边，白色圆领毛衣，读信后抬眼微笑，固定中景。”

保存草稿只留档；**保存并设为当前版本**才更新下一步引用。按钮会检查未设置的当前版本和缺少的参考图。

## 3. 生成视频

选择适合目标平台的路线：

| 路线 | 需要做什么 |
|---|---|
| 直接用提示词 | 手写或 AI 辅助整理动作、节奏和镜头描述 |
| 参考视频 | 导入实际视频，标注动作与时间范围，确认平台支持参考视频输入 |
| 需要首帧的图生视频 | 在节点内准备图片词、回填候选并选定当前首帧，再写视频词 |

参考视频可以播放并提取关键帧。图片模型只能分析所选图片；连续动作、音轨和精确卡点需要实际观察，不能由稀疏截图推断为已验证。

### 写提示词

保存当前输入后点击“AI 辅助视频词”，先查看完整指令，再发送给配置的文本/视觉模型。

没有 API 时，在预览里复制完整指令到外部对话平台，展开外部结果入口并粘贴 JSON 或正文。模型只负责写词；媒体在你常用的平台生成。

需要模型看图时，选择发送相关图片。若未配置视觉模型，界面会立即提示。连接页可测试文本与图片请求，并显示最近测试结果。

### 首帧准备

只有图生视频路线展开首帧区：

1. 组合基础图片词，或手写、AI 优化。
2. 保存当前版本，复制到生图平台，按平台能力上传人物参考。
3. 在素材箱上传候选图片，核对作品和提示词版本。
4. 在图片候选中设定当前图片，再生成视频提示词。

更换人物、主题或参考条件会清空待用视频正文，旧版本和实际结果继续保留。

### 回填与候选视频筛选

生成完成后把视频拖入素材箱。能够识别当前作品时，结果会直接进入候选视频列表；多个结果按导入时间标为“候选 V1、V2…”，再从中设定当前视频。

- J/K 或左右键切换。
- A 设为当前结果。
- R 标记返修，先写一句预期与实际差异。
- X 淘汰，记录仍可保留。
- 勾选同作品 2–4 个候选可比较实际提示词、模型、参数和输入素材。

有旧版本提醒时，先对照当前设定检查，再决定是否复核继续使用。原始生成用词不会被复核记录覆盖。

返修使用“修改此镜头词”，把问题带回本节点；保存新版本，再生成下一批结果。

## 4. 导出与下一条

选定当前视频、补齐版本与参考条件后，下载当前作品包，包含视频、可用封面、提示词和参考素材清单。

可以将主题保存为模板，或点击“沿用人物再做一条”。历史作品保留各次输入、结果与版本；套用模板不会复制已完成状态。

旧日常/穿搭/舞蹈项目和旧图片作品继续保留。新四步流程以视频交付为完成标准，旧图片可预览和下载。

## 数据与使用范围

工程备份带走全部作品、人物、媒体与历史，恢复创建新项目。项目删除进入回收站，至少保留 30 天，只有主动永久清空才删除媒体。

桌面适合模板、批量关联与精细编辑；手机适合进度查看、上传、预览和快速筛选。使用原创或有相应用途授权的人物素材，发布规则以目标平台为准。
