# AI 美女使用说明书

更新：2026-09-28 · 适用映序 v1.1

**只走三步：选人物与玩法 → 生成提示词 → 到公开 AI 平台生成并回填。**

一条作品可以是一张满意的图片。只有想让它动起来时，才继续做视频。这里不需要编剧本、拆分镜或配置 ComfyUI 工作流。

## 1. 创建项目

1. 打开 http://127.0.0.1:8765，点击顶部 **AI 美女** Tab。
2. 点击 **创建美女项目** 或侧栏 **＋ 新建项目**。
3. 填项目名称、默认画幅和方向。

一个项目里可以保存多位人物、多条作品。日常、穿搭、舞蹈在每条作品内选择，不需要为了换玩法另建项目。

侧栏只有三个页面：

| 页面 | 用途 |
|---|---|
| 快速创作 | 输入想法、生成提示词、回填和返修 |
| 人物库 | 保存人物参考图及稳定特征，重复使用 |
| 作品与收藏 | 打开历史作品、收藏提示词模板、套用创作 |

旧版日常、穿搭、舞蹈项目会归到这个 Tab，原数据和版本保留。旧镜头可以在作品列表打开，旧阶段文本在 **历史阶段记录** 展开查看。

## 2. 建立人物，只需第一次做

### 已有参考图

1. 进入 **人物库 → ＋ 新建人物**。
2. 填人物名、稳定特征和常用造型。
3. 点击 **导入参考图**，选定图片。
4. **保存并接受**，以后点击人物卡上的 **用她创作**。

先用一张脸和发型清楚的图片即可。项目内的人物可跨日常、穿搭、舞蹈复用。

### 还没有人物图

1. 在人物库点击 **先写人物形象词**。
2. 在快速创作里描述一位成年原创虚拟人物。
3. 组合基础图片词或让文本模型优化，复制到生图平台生成。
4. 回填图片，实际检查后标为 **可用**。
5. 在结果卡点击 **保存为人物**，填写人物名和稳定特征。

人物库保留这张实际图片及其来源结果，后续可以继续换服装和场景。

## 3. 新建一条作品

进入 **快速创作**，填写左边：

- **人物**：选择人物和参考版本，也可以暂不选择，设计新人物。
- **这次做什么**：日常、穿搭或舞蹈。
- **一句话想法**：这张图要表达的具体内容。
- **生成平台 / 模型**：记录你准备使用的平台，可以暂时留空。
- **画幅**：通常选择 9:16 竖屏。
- **可选参考**：服装图、参考视频、关键帧、时间范围或其他要求。

例如：

> 咖啡店窗边，白色圆领毛衣，坐姿放松，手放在桌面，午后自然光，真实生活抓拍感。

作品名称可以自己填，留空时使用想法前面的文字命名。

## 4. 获得图片提示词

右边的 **可复制图片正文** 可以直接编辑，有三种写法：

### 方法 A：组合基础图片词

点击 **组合基础图片词**。工作台把人物特征、想法、玩法、画幅和光线组织成文本。

此操作不调用模型，没有 API 费用。它是固定规则组合，适合快速试图；复杂构图可以再做 AI 优化。

### 方法 B：文本 / 视觉模型优化

1. 点击 **生成 / 优化图片词**。
2. 预览完整指令和图片数量。
3. 确认后点 **发送给文本 / 视觉模型**。
4. 返回结果载入图片正文，检查并修改。

只调用已配置的文本/视觉模型来写提示词，**不会调用生图 API**。文本模型本身是否收费取决于你配置的服务。

默认只发送文字。若想让模型理解人物/服装参考图，勾选 **允许本次提示词优化发送相关图片给视觉模型**，并配置支持图片输入的模型；预览会列出实际发送的图片。

### 方法 C：在外部对话平台写词

1. 打开同一个生成预览，点击 **复制完整指令**。
2. 到外部对话平台粘贴指令，需要时手工上传参考图片。
3. 回到预览弹窗，展开 **无 API：粘贴外部对话平台的结果**。
4. 粘贴返回的 JSON 或单段图片提示词，点击 **载入外部结果**。

如果自己已经写好提示词，也可以直接粘贴到右侧正文。

## 5. 去公开 AI 平台生成，再回填

1. 点击 **保存并复制图片词**，工作台先保存这次提示词版本。
2. 去常用平台的生图入口，粘贴正文。
3. **同时上传人物参考图**；穿搭有服装参考时也按平台支持情况上传。
4. 下载结果，回工作台点击 **回填图片**，或把文件拖到结果区域。
5. 确认实际用的是哪个提示词版本、哪个平台；外部改过正文要填写实际用词。
6. 导入结果，填写反馈，检查后选择 **可用** 并勾选已实际检查。
7. 点击 **保存结果记录**，再点击结果卡上的 **采用图片**。

到这里，一条图片作品就完成了，不需要继续视频流程。

上传到工作台只表示本地留档；不会自动把图片送到外部生成平台。仅重复人物外貌文字，也不能保证每次生出同一张脸。

## 6. 三种玩法怎么用

| 玩法 | 建议输入 | 第一轮怎么做 |
|---|---|---|
| 日常 | 人物图＋生活场景＋一个想法 | 自然光、简单姿态，先确认脸和生活感 |
| 穿搭 | 人物图＋服装图/具体描述 | 一套衣服一条作品，检查领口、袖长、版型和配饰 |
| 舞蹈 | 人物图＋舞蹈风格，可选参考视频 | 先生成全身起始图，四肢完整可见并留动作空间 |

舞蹈需要区分两个目标：

- **风格近似**：用文字描述舞种、方向、幅度和节奏意图。
- **准确跟跳**：目标平台必须支持参考视频驱动；提示词不能单独替代连续动作输入。

参考视频在人物库的素材列表中可以播放、提取关键帧。图片模型只能分析选中的图片，不能据此确定完整舞步、音轨或精确卡点。没有视觉模型时，可在 **参考内容 / 时间范围** 手工写清要借鉴的部分。

## 7. 可选：让图片动起来

先回填并 **采用图片**，再展开 **让选定图片动起来**：

1. 点击 **生成视频提示词**。
2. 按预览生成或粘贴外部结果。
3. 检查动作是否适合当前图，例如“抬眼 → 微笑 → 停顿”，避免一次塞很多动作。
4. 点击 **保存并复制视频词**。
5. 去支持图生视频的平台，上传这张已采用图片，粘贴视频正文。
6. 使用 **回填视频 / 截图** 记录生成结果，检查后采用。

图片和视频分别记录采用版本。采用视频不会抹掉已经选中的图片。

修改人物、玩法、想法、画幅、参考条件或图片正文后，待用视频正文会清空，旧视频词仍保留在历史中。换选另一张图片后，已经保存的视频词仍指向原图，页面会提醒复核；重新生成视频词才会绑定新图。

## 8. 不满意就局部返修

1. 回填失败结果，在反馈里说明预期和实际。
2. 点击该结果的 **据此返修**。
3. 在 **返修：这次只改哪里** 中补充要求。
4. 点击 **修图片词** 或 **修视频词**。
5. 检查新正文，保存并复制，再去平台重试。

例如：

> 人脸保留正确，但白色圆领毛衣变成衬衫。这次只固定领口和衣服材质，保持构图与光线。

旧版、失败结果、实际平台及用词都保留。若问题来自没有上传参考图或平台缺少动作驱动能力，修改文案不一定能解决。

## 9. 收藏与下一条作品

进入 **作品与收藏**：

- **打开**：继续编辑或查看某条作品的结果。
- **收藏为模板**：保存当时的提示词、素材条件及关联版本。
- **查看**：阅读收藏内容。
- **套用创作**：创建新草稿，继承图片提示词和输入条件，重新选图后再做视频。

没有已采用结果的收藏会注明是草稿模板。成功过一次，也只代表当时的平台和素材组合有效。

套用不会复制“已完成”状态，不会把旧结果当成新作品，也不会直接沿用旧图对应的视频提示词。

## 10. 保存、备份与注意事项

- **保存草稿**、**保存并复制** 会形成新修订。
- 底部 **提示词历史** 可载入旧版，保存为新版本。
- 切换页面、项目或 Tab 时，未保存内容会提醒确认。
- **工程备份** 带走全部作品、人物、素材和历史；**恢复工程** 创建新项目。
- **导出交接包** 用于带走提示词和已选结果；完整迁移请使用工程备份。
- 单文件上限 256 MB；视觉请求最多 8 张图片、合计 20 MB。
- 工作台不会自动检查图片或视频质量，“已检查”是你的人工作业记录。
- 使用成年原创虚拟人物或具有相应用途授权的成年人物素材；发布时按平台要求标识 AI 生成内容。

可先用“一个人物＋咖啡店日常＋一张图片”走完一遍，再尝试穿搭或视频。
