# AI 漫剧使用说明书

更新：2026-09-30 · 提示词模板 v0.4

**编写剧本 → 剧本分镜 → 角色一致性 → 文字生图 → 图生视频 → 人声配音 → 导出。**

图片、视频和配音在你常用的平台生成；工作台管理当前版本、实际输入、候选结果和交付。

## 创建与保存

打开 http://127.0.0.1:8765，选择 AI 漫剧并创建项目。顶部“当前集”决定本次范围，默认 EP001。

- **保存草稿**：保留编辑，不改变下游引用。
- **保存并设为当前版本**：保存并更新后续步骤使用的版本。
- **完成并进入下一步**：检查上游；缺项会显示原因与返回入口。

人物、模板、来源和配方可以从左侧工作空间共享库复制到当前项目。复制后两个项目独立修改。

## 1. 编写剧本

本节点直接管理三类改编来源：

- **小说**：导入小于 1 MB 的 TXT/Markdown，或粘贴原文；在“起始文字”和“结束文字”两个空里标出本次改编范围。
- **漫画**：上传页面图片，按页填写人工校对的画面、对白、说话人和阅读顺序。
- **段子**：粘贴原文，注明必须保留的铺垫、反转或包袱。

来源需要先保存并设为当前版本。展开“用来源素材生成剧本”，分别填写本次改编范围的起始文字和结束文字并选择来源；漫画图片只在已配置视觉模型且明确勾选时发送。没有视觉模型时填写人工画面描述。

点击“生成剧本预览”检查完整指令后发送。没有 API 时，复制指令到外部对话平台，再把结果粘贴回“本集剧本”。检查故事、对白、旁白、来源锚点与时长后，保存并设为当前版本。

## 2. 剧本分镜

使用 M01 将当前剧本拆成镜头，提取人物、场景和道具。JSON 结果含 `text`、`shots` 和 `assets`。

镜头使用稳定镜号，如 `EP001-S001`；`duration` 为秒，`order` 为排列顺序，`dialogue` 为对白。填写画面起点、动作、落点和景别。
新模板不再限制为 8–15 镜。完整保留剧本顺序与台词，时长不足时给拆镜/拆集建议。`composition` 记录站位构图，`lighting` 记录光源，`continuity` 记录接续状态，`asset_ids` 指定本镜实际角色、造型和道具；这些都可在镜头详情修改。

保存为当前版本后，点击“同步镜头与资产”。在本节点展开镜头与资产详情，检查人物特征、顺序、时长和三视图提示词。

若镜头显示“上游内容已更新”，说明它的图片提示词仍基于旧人物、场景或剧情版本。点击“用最新设定重新生成”进入文字生图，按当前来源和资产重新生成并保存；展开“查看变更明细”可核对具体变化。

## 3. 角色一致性

每个角色资产都要先确定三视图。打开角色资产，检查或点击“组合三视图提示词”。配置了 ComfyUI 图片 workflow 后，可在角色卡片点击“ComfyUI 生三视图”；生成结果会进入“候选三视图”，由你筛选后设为当前三视图。也可以把外部平台生成结果手动导入候选图。

角色三视图未确认时，流程会停在本节点，不进入文字生图。场景、道具可以继续只保存参考图或文字说明。
同一个人的人形、本体、半变身使用“造型”资产，填写“所属角色”和“形态与变化边界”，不要建成多个独立人物。螳螂本体按非人结构写设定；普通道具、建筑不需要三视图。

资产详情可另选“单人生产参考”：例如从设定图手工裁好的清晰单视角。三视图用于对照身份，剧情静帧使用单张画面，避免把设定板拼接排版一起生成。新镜头按实际关联资产检查角色；未填写资产列表的旧镜头沿用原选择逻辑。

## 4. 文字生图

左侧选镜头，中间编辑当前图片提示词；高级参数与历史在详情中。批量生成入口使用 M02，结果保存后同步至镜头。
M02 每批最多 6 镜，预览展示所有批次实际指令。结果只更新图片词、ControlNet 建议和参考用途，保留原对白、时长、顺序及真实素材绑定。每条图词会要求写清当前形态、可见服装、静态姿态、道具关系、空间、构图、光源与画风，首帧不提前画动作结果。

默认每次输出上限为 8192 tokens，可在“模型连接设置”按服务支持上限调整。模型漏镜、重复镜号或截断时会保留失败记录；打开“模型生成记录”查看各批原始输出。可只选择失败镜号重新预览生成，再将完成的结果合并或分次应用，不需要重跑成功镜头。

预览会显示内置/项目自定义模板及版本。已有自定义模板仍生效；要采用新版，在项目提示词模板里“载入内置模板”并保存。无 API 时把预览中每一批分别发送到外部对话工具。

到生成平台复制图片正文，并按平台能力上传人物和场景参考。人物名字和外貌文字不能代替实际参考图。

逐镜“ComfyUI 生图”仍是后续连接完整图片工作流的固定入口；角色三视图已支持按配置的 ComfyUI 图片 workflow 一键生成。

生成后在同页“候选图片筛选”中导入结果：

1. 一次选择或拖入最多 200 个结果。
2. 文件名包含完整镜号时自动匹配当前提示词版本并直接进入候选列表；无法识别时再统一手选镜头，或按文件修改时间、每镜候选数顺序匹配。
3. 列表按镜头顺序排列，同镜图片按导入时间显示为“候选 V1、V2…”，提示词版本单独显示。
4. 在外部改过词或参数时补填实际值，再筛选当前图片。

| 操作 | 按钮 / 快捷键 |
|---|---|
| 上一个 / 下一个 | J / K 或左右键 |
| 检查后设为当前结果 | A |
| 返修并保留意见 | R，先填写一句返修意见 |
| 淘汰但保留记录 | X |
| 同镜对比 | 勾选 2–4 个候选，点击并排对比 |

快捷键在文本输入、弹窗和未保存编辑期间停用。旧提示词对应的结果会显示版本；对照当前设定重新检查后，可勾选复核记录，原始生成输入仍保留。

每镜选定一张当前图片后进入视频。

## 5. 图生视频

进入此节点会将当前图片绑定为实际首帧。通过 M03 批量整理视频提示词，或直接逐镜编辑；一镜以一个主要动作为宜。
M03 同样每批 6 镜，只更新视频词与后期说明，并保留原后期备注。视频词从首帧起点写动作、反应、单一主运镜和结束落点，下一镜的事件不能提前出现。未发送图片时只依据文字状态；画面是否正确、是否连续仍需生成后人工判断。

复制到支持图生视频的平台，同时上传首帧。视频结果仍在本节点的“候选视频筛选”中导入，自动按镜头排列。

“ComfyUI 生视频（待接入）”同样仅预留入口，目前不会提交任务。

在完整记录里保留实际模型、参数、参考输入和用词。胜出结果可一键保存为配方；单个样本不代表其他模型或素材条件一定有效。

## 6. 人声配音

导入外部配音音频，逐镜选择音轨，记录说话人、音色、语速和情绪。可直接试听。

台词时间轴使用 JSON，每句填写 `speaker`、`text`、`start`、`end`，时间相对于本镜、单位为秒，不得超过镜长。例如：

```json
[{"speaker":"林岚","text":"我们出发。","start":0.5,"end":3}]
```

没有对白或不需要配音时，明确勾选“本镜无配音”并保存。工作台不直接调用语音生成平台。

## 7. 导出

检查当前集的草稿、上游变化、当前图片/视频和配音。缺项可直接返回对应节点。

通过后下载交付 ZIP：视频、音轨、整集 SRT 字幕、对白 JSON、逐镜提示词、镜头表和参考素材。仅导出当前集，完整项目迁移使用工程备份。

交付包不是 ComfyUI 节点 JSON，后续剪辑和发布在外部工具完成。

## 回收站与备份

项目、未使用的来源和可删除历史版本默认移入回收站，至少保留 30 天，到期不会自动清理。恢复后保留原记录和媒体；永久清空前展示影响范围并核对名称。只有永久清空项目才删除其媒体文件。

工程备份包含全部版本、媒体和回收站记录。恢复创建新项目，不覆盖原项目。API Key 保存在本机项目外，不进入工程备份。

桌面适合批量编排和时间轴编辑；手机适合查看、上传、预览与快速筛选。
