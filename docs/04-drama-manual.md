# AI 漫剧使用说明书

更新：2026-09-28 · 适用映序 v1.1

**一条主线：素材 → 剧本与分镜 → 角色参考图 → 逐镜图片 → 动态片段 → 剪辑与复盘。**

工作台负责提示词、参考素材、版本和结果记录。你把最终提示词复制到常用公开 AI 平台生成图片或视频，再将结果带回工作台。ComfyUI 也可以使用，但不是必需。

## 1. 打开与创建项目

1. 启动工作台，打开 http://127.0.0.1:8765。
2. 点击顶部 **AI 漫剧** Tab。
3. 点击 **＋ 新建项目**，填写项目名、画幅、单集目标时长和画风。
4. 顶部 **当前集** 默认 `EP001`。做下一集时改成 `EP002`。

两个 Tab 的项目列表分别显示。人物、素材、结果属于各自项目，不会因为切换 Tab 被混用。

想先熟悉操作，可以在空项目页打开原创示例。示例仅提供文字草稿，没有真实出图或视频。

## 2. 准备素材

进入 **素材与定位**：

- 小说：点击 **导入 TXT / Markdown**，也可以新增来源并粘贴正文。
- 漫画：导入图片，在来源中说明页码、对白和本次改编范围。
- 保存前填写来源位置，检查正文，点击 **保存并接受**。
- 图片和视频通过 **选择文件** 导入素材库。

建议先用一小段素材做一集，确认人物和画风后再扩大。每次模型请求的完整指令最多 8 万字符，过长时按章节缩小范围，不会自动截断小说。

只有被选中的已接受来源会进入本次生成；没选的章节不会被自动读完。

## 3. M01：剧本与 JSON 分镜

进入 **剧本与分镜 → M01 剧本分镜**：

1. 勾选这次使用的来源。
2. 填写目标，例如：`本集 45 秒，约 9 镜，前三秒出现冲突，结尾留悬念。`
3. 点击 **生成前预览**，确认文字和图片范围。
4. 获取草稿后检查人物、剧情、镜长和原文覆盖范围。
5. 点击 **保存并采用**，再点 **同步到镜头 / 资产**。

M01 产出单集剧本、角色草案和 JSON 分镜。图片词和视频词在后两步生成，避免一次输出过长。

同步后会进入 **角色一致性**。每个镜头都有固定镜号，如 `EP001-S001`，后续优化保留原镜号。

### 两种获取草稿的方法

| 方法 | 操作 |
|---|---|
| 已配置文本 API | 在预览弹窗点击 **发送给模型生成**，结果载入编辑器 |
| 不使用 API | **复制指令**到外部对话平台，把返回 JSON 粘贴到 **阶段结果** |

这里的“流程指令”交给对话模型；后面生成的“图片正文”才复制到生图入口。需要同步镜头时，阶段结果应保留包含 `text`、`shots`、`assets` 的 JSON。

## 4. 选定角色参考图

进入 **角色一致性**：

1. 点击角色卡片的 **编辑 / 选图**。
2. 查看或补充稳定外貌、服装和参考图提示词。
3. 将参考图提示词复制到常用生图平台，先生成一张清楚的人物图。
4. 回到角色编辑弹窗，点击 **导入参考图**，选择并保存。
5. 每次生成该人物的分镜时，在外部平台另行上传这张参考图。

人物名字和外貌文字只能帮助保持设定，不能代替平台的参考图输入。平台不支持参考人物时，跨镜一致性需要人工反复挑选。

LoRA、IP-Adapter 和统一命名放在可选设置中；只走公开平台时可跳过。

## 5. M02：生成逐镜图片提示词

进入 **批量出图 → 生成 / 优化出图词**：

1. 检查预选的剧本、镜头和角色版本。
2. 补充画风或平台要求，例如：`中文自然语言，竖屏，保持人物参考图的面部和发型。`
3. 预览、生成、检查，点击 **保存并采用**。
4. 点击 **同步到镜头 / 资产**，返回出图队列。
5. 使用单镜 **复制图片词**，或 **复制全部图片词** 导出整集文本。

**“复制全部”只是批量复制提示词，不会替你向各个平台提交任务。** 请按镜号逐张生成。

得到满意的图片后：

1. 在 **素材与定位** 导入图片。
2. 回到 **批量出图 → 编辑 / 绑定图片**。
3. 在 `first_frame` 中选择对应图片，可填写生成平台/模型。
4. 保存新修订，再打开该镜头，点击 **接受当前已保存版本**。

公开平台不要求绑定 ComfyUI 档案。只有确实使用节点工作流时才展开可选设置。

M02/M03 同步已有镜头会保留用户绑定的真实图片；模型输出中的素材 ID 不会作为真实文件使用。

## 6. M03：让分镜图动起来

进入 **图生视频 → 生成视频提示词**：

1. 检查预选镜头及其起始图、人物设定。
2. 每镜以一个主要动作和固定镜头/简单运镜为主。
3. 预览、生成、保存并采用，再同步到镜头。
4. 复制对应镜头的 **视频提示词**，到支持图生视频的平台，同时上传该镜头起始图。

如果要让提示词模型看图，必须在生成输入里明确勾选图片，并配置视觉模型。没有发送图片时，它只依据已保存的文字描述，不代表已经检查过真实画面。

首尾帧、参考视频驱动、对白或音乐等能力以目标平台实际支持情况为准。声音、字幕和复杂剪辑可留到后期。

## 7. 回填、采用与返修

在 **图生视频** 找到对应镜头，点击 **回填**：

1. 确认实际使用的提示词版本。
2. 填写实际平台、实际用词和已知参数；外部改过词，要记录改后的版本。
3. 导入结果，核对实际输入素材。
4. 填写反馈，例如：`00:02 人物右手变形，下一次只减小手部动作。`
5. 设为 **可用** 并勾选已实际检查，保存后点 **采用此结果**。

不满意时设为 **需返修**，点击 **返修 →** 进入 Q01。优先只改一个主要问题，旧提示词和失败结果继续保留。

“接受提示词”表示认可文字版本；“采用结果”表示你检查并选中了实际媒体，两者分别记录。

## 8. 剪辑与复盘

进入 **成片复盘**：

- **导出剪辑交接包**：包含逐镜提示词、资产说明、镜头表、关联输入和已采用结果。
- 你在外部工具完成配音、字幕、剪辑与发布。
- 可以手工记录作品链接、播放、完播率和观察窗口。
- 成功组合保存为配方；不同平台、模型或输入条件需要重新验证。

交接 ZIP 是文本和素材包，不是可直接导入的 ComfyUI 节点 JSON。

## 9. 备份与删除

- **工程备份**：包含全部素材、版本和尝试，适合跨电脑迁移。
- **恢复工程**：创建新项目，不覆盖已有项目；模型密钥需在新电脑重新填写。
- 项目选择框旁 `×`：输入完整名称后删除项目及其媒体。
- 来源卡片及历史版本旁 `×`：删除未使用的来源/废弃历史版。
- 当前采用版本、仍被下游引用的来源或版本不能删除。

默认数据存放在 `~/.ai-prompt-studio/data/`，API Key 单独保存在项目外，不进入工程备份。

## 10. 常见问题

| 现象 | 处理 |
|---|---|
| 同步按钮提示需要 JSON | 粘贴完整结构化结果，再保存并采用 |
| 角色变脸 | 核对平台是否实际上传了同一人物参考图及相关控制 |
| 提示上游变化 | 检查新版角色/剧本是否影响当前镜头；不要直接重做整集 |
| 输出中断或格式错误 | 保留失败草稿，减少单次镜头或素材量后重试 |
| 想只用公开平台 | 文本 API 可选；生图、视频 API 均不需要接入 |
| 结果文件很大 | 单文件上限 256 MB；先裁成实际镜头片段 |

发布时确认小说/漫画改编、人物素材和音乐的相应用途授权，并按平台要求标识 AI 生成内容。
