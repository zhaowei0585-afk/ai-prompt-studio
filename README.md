# 映序 · AI 提示词工作台

一个本地运行的中文创作工作台，提供 **AI 漫剧 / AI 美女** 两个独立 Tab，管理提示词、参考素材和生成结果。

| Tab | 使用流程 | 使用说明书 |
|---|---|---|
| AI 漫剧 | 编写剧本 → 剧本分镜 → 文字生图 → 图生视频 → 人声配音 → 导出 | [AI 漫剧使用说明](docs/04-drama-manual.md) |
| AI 美女 | 选择人物 → 选择今日主题 → 生成视频 → 导出 | [AI 美女使用说明](docs/05-beauty-manual.md) |

工作台负责写提示词与留档；你复制到常用公开 AI 平台生成，再回填结果。ComfyUI 仍可选用，不要求接入生图或视频 API。页面侧栏的「使用说明书」会打开当前 Tab 对应的手册。

## 启动

安装 **Python 3.9 或以上**，无需安装 Python 包、Node.js 或 GPU 模型。

- Windows：双击 `start.bat`。
- macOS：双击 `start.command`；如果权限不足，在终端执行 `sh start.command`。
- Linux / 通用启动：在项目目录运行 `python3 studio.py`；Windows 也可以运行 `py -3 studio.py`。

浏览器自动打开 **http://127.0.0.1:8765**。保持终端窗口打开，按 `Ctrl+C` 退出。

```bash
# 端口冲突时
python3 studio.py --port 8766
# 自定义数据目录，不自动打开浏览器
python3 studio.py --data-dir /path/to/studio-data --no-browser
```

第一次打开，可以点击 **「打开原创示例」**，查看《雨夜失物》三个相互关联的镜头。示例只有原创文字与提示词草稿，没有实际参考图和生成视频。

## 从零走通一集

1. **编写剧本**：在节点内导入小说 TXT/Markdown、添加漫画页或粘贴段子，选择范围后用 M00 生成可编辑剧本，保存并设为当前版本。
2. **剧本分镜**：M01 根据当前剧本拆镜、提取人物与场景，校对 JSON 后同步。
3. **文字生图**：在节点中编辑逐镜图片词，到外部平台生成；批量回填并选定每镜当前图片。
4. **图生视频**：沿用选定首帧，编辑视频词并到外部平台生成，批量回填与判片。
5. **人声配音**：导入外部配音，登记说话人、音色、情绪和逐句时间；无配音的镜头需明确标记。
6. **导出**：检查当前集的版本、缺项和过期引用，通过后打包视频、配音、SRT、提示词与素材清单。

旧版 D01–D06 和 M01 数据仍保留。旧剧本可继续作为交付检查依据；同步 M02/M03 会保留真实图片绑定。

素材箱单批支持 1–200 个结果，按文件名、文件修改时间或手动选择关联镜头；确认提示词版本后生成待判片记录。J/K 或左右键切换，A 设为当前、R 返修、X 淘汰。支持同镜 2–4 个候选并排比较用词、模型、参数与输入素材，并从胜出结果保存配方。

**保存草稿不会改变下游引用；设为当前版本才生效。** 进入下一步前会检查上游，展示缺项和实际引用版本。行动中心汇总未设当前、待判片和待复核内容。

镜头显示“上游内容已更新”时，表示当前图片提示词仍基于旧人物、场景或剧情版本。点击“用最新设定重新生成”会进入文字生图节点并定位该镜头；系统不会用新引用冒充已经更新过的提示词。

## 从零做一条 AI 美女作品

1. 切换 **AI 美女** Tab，创建项目。
2. **选择人物**：新建带参考图的人物，或从工作空间共享库导入，保存为当前版本。
3. **选择今日主题**：选择日常、穿搭或舞蹈主题，填写想法、画幅、平台和时长。
4. **生成视频**：选择直接提示词、参考视频或需要首帧的路线。首帧准备在此节点内完成，不是固定一级步骤。
5. 到外部平台生成，再在素材箱批量回填候选视频，实际检查后设为当前结果。
6. **导出**：检查通过后下载当前作品包；可以保存主题模板，或沿用人物再做一条。

人物、来源、模板、配方与模型档案可从共享库跨项目复制。复制后各自修改，原项目不会被联动改写。旧人物项目统一归入 AI 美女，旧图片和历史阶段继续保留，四步流程以视频交付为完成标准。

**视频参考**：素材库里打开视频，暂停到目标位置，点击提取当前帧，会保存截图与时间码来源记录。浏览器需支持视频编码，建议 MP4/H.264。图片模型只能分析抽到的画面，不能据此确认完整舞步、速度、音轨或原始提示词。

**舞蹈路线**：近似风格可用普通 I2V；精确跟随需要真实动作驱动视频和兼容工作流。Wan-Animate-2 的文字重点是外观与背景，不能用长篇文字替代驱动输入。

## 连接模型

点击左下角 **「模型连接设置」**：

| 设置 | 填写内容 |
|---|---|
| API Base URL | 兼容服务的地址，到 `/v1`，例如 `https://api.openai.com/v1` |
| 文本模型 | 服务实际支持的模型 ID |
| 视觉模型 | 可选，填写能接收图片的模型 ID；仅填名称不会让纯文本模型具备视觉能力 |
| API Key | 供应商密钥；本机免鉴权服务可留空 |

使用 OpenAI 兼容的 `/chat/completions` 接口，支持远程 HTTPS 与本机 HTTP。发送前会显示完整指令、所选来源和图片数量。接口请求最多等待 5 分钟；被截断或格式错误的返回保存为失败草稿，不能直接标记完成。

连接保存后可测试文本请求和图片输入，显示最近测试时间及失败原因。测试只验证最小请求兼容性，不代表完整视觉能力或生成质量。没有接入默认付费服务，也不会在打开项目时自动调用模型。

## 搬到另一台电脑

**程序与创作数据分开保存：**

- 程序：从 GitHub 克隆，或下载源码 ZIP，解压后启动。
- 工程：在旧电脑点「工程备份」，把 ZIP 带到新电脑，在工作台点「恢复工程」。
- 模型密钥：在新电脑重新填写。

工程备份包含全部版本、来源、素材、试片、选择记录和模板修改。恢复会创建新项目，不覆盖已有项目；导入前会校验路径、文件大小和 SHA-256。

通常，上游当前版本变化会提醒下游复核。旧阶段结果及其下游被用于修订同一阶段时，会固定为历史快照，预览会标注，避免新结果依赖自身。资产和镜头可以在人工校对后勾选“改用上游当前版本”；历史记录仍然保留。

项目选择框旁的 `×` 会将项目移入**回收站**，至少保留 30 天，到期不会自动删除。来源和废弃版本也可恢复。只有主动永久清空项目才删除项目媒体，清空前展示影响范围并核对名称；仍被历史引用的记录不能永久清空。

默认数据目录：`~/.ai-prompt-studio/data/`，Windows 对应 `%USERPROFILE%\.ai-prompt-studio\data\`。密钥位于同级的 `settings.json`，不会进入 Git 或工程备份。不要把自己的密钥写进素材备注或提示词正文——正文是工程数据，会随工程导出。

| 导出 | 包含什么 | 用途 |
|---|---|---|
| 工程备份 | `project.json`、全部素材、全部版本及试片记录 | 跨电脑恢复、个人备份 |
| 交接包 | `prompts.md`、`assets.md`、`shots.csv`、`manifest.json`、`voice-lines.json`、`subtitles.srt`、关联输入及当前结果 | 当前集 / 单作品的剪辑交付 |

**交接包不是 ComfyUI workflow JSON，不能直接导入成节点工作流。** 页面在检查通过后导出；失败结果不作为成片打包。完整迁移使用工程备份。

## 首版边界

- 单人、本机应用，只监听 `127.0.0.1`。不提供公网部署或多人同步。
- 文本按章节手工分段；漫画按页导入和校对；视频手工定位抽帧。尚无自动长篇分批执行、OCR、自动切镜或完整视频理解。
- 版本、依赖和当前结果记录可追溯。页面只检查字段与输入条件，不能保证叙事质量、人物一致性或视频合格。
- 单个素材最大 256 MB，恢复工程解压后最大 1 GB，每次最多 8 张、合计 20 MB 视觉输入。大量长视频建议先剪成镜头片段。
- 软件验证使用临时工程和模拟模型，不代表真实图片质量。先试一张人物图或三个短镜头，按目标平台的实际能力扩大生产。

## 开发与检查

后端使用 Python 标准库 HTTP、SQLite 与本地文件；前端使用原生 HTML/CSS/JavaScript，没有构建过程或运行时第三方依赖。

```bash
python3 checks/smoke.py
python3 checks/production.py
node --check web/app.js
node --check web/beauty.js
node --check web/production.js
```

集成检查通过临时目录和模拟模型服务验证：并发编辑冲突、依赖过期、媒体范围读取、可投产条件、当前结果选择、ZIP 往返与路径攻击、密钥排除、模型输入快照、视觉请求和失败草稿保存。不会调用付费 API，也不修改个人工程。

可选浏览器检查需要安装 Google Chrome 和开发用的 Playwright（`pip install playwright`），运行 `python3 checks/browser.py`。使用隔离临时工程验证 30 镜 × 4 候选批量回填、判片、四步视频创作、交付、回收站和移动端布局；不接触个人工程或真实模型密钥。

真实平台出片质量和 Windows/Linux 实机启动需另行验证。
