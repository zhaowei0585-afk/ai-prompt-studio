# 原创流程示例：《雨夜失物》EP001

**性质：本轮原创文本演示。没有实际参考图或生成视频；所有提示词均为待适配、待试拍草稿。后面的失败与返修是演示情境，不是观察结果。**

目的：用三个镜头展示上游内容如何被后续复用，以及局部失败怎样返修。

## 1. 项目与来源

| 字段 | 值 |
|---|---|
| 项目 | `RAIN-KEY` |
| 赛道 | AI 悬疑漫剧 |
| 画幅/风格 | 9:16，二维电影感漫画 |
| 本集剪辑预算 | 15 秒，三个镜头各 5 秒 |
| 实际生成时长/帧数 | 未知，按用户工作流可用档位设置，后期裁切 |
| 视频路线 | 普通 I2V 的通用示意，尚未验证 |

原创来源 `SRC-001`：

> P1：雨夜，修表师林岚站在店内柜台后，发现木台面多了一把系红线的铜钥匙。
>
> P2：她用右手拿起钥匙，红线垂在指间。
>
> P3：左侧画外传来三下敲门声。她保持拿着钥匙的姿势，转头看向左侧店门。

不可擅改的事实：右手持钥匙；红线属于钥匙；门在人物视线左侧；敲门声由后期加入。

## 2. 创意与分集关联

一句话故事：修表师每晚收到一件无人认领的物品，每件物品都指向店铺过去发生的一件事。

| 集号 | 本集目的 | 结尾/进入状态 |
|---|---|---|
| EP001 | 发现第一件异常物品 | 林岚右手持红线铜钥匙，看向左侧店门 |
| EP002（提案） | 确认门外是谁 | 从 EP001 的持物和视线状态衔接；具体情节待创作 |

这里只给后续方向，未编写整部剧。真实长篇项目需要先用 `D02` 完成指定范围的全剧地图。

## 3. 剧本与资产

场次 `SC001`：内景，修表店，雨夜。

林岚低头注意到柜台上的钥匙。她右手拾起钥匙，停在台面上方。画外响起三下敲门声，她转头看向左侧。

| ID/版本 | 内容 | 实际参考状态 |
|---|---|---|
| `CHAR-LIN v1` | 原创成年女性，28岁，椭圆脸、黑色齐肩短发、眼下轻微倦意 | 待提供 |
| `LOOK-LIN-01 v1` | 米白衬衫、深棕工作围裙，无首饰 | 待提供 |
| `LOC-SHOP v1` | 木柜台、后方钟表架、画左方向店门；右侧暖台灯 | 待提供 |
| `PROP-KEY v1` | 单把旧铜钥匙，圆形钥匙头系一根短红线 | 待提供 |

角色参考图提示词：

```text
二维电影感漫画角色设定，单个人物，全身正面站姿。
一名28岁的成年女性修表师，椭圆脸，黑色齐肩短发，神情专注，
穿米白衬衫和深棕色工作围裙，没有首饰，双手自然垂放。
浅灰色纯净背景，柔和均匀照明，清楚的轮廓线和克制的色块，
脸部、衣领、围裙和双手清晰可见，画面不含文字。
```

用户出图并选定后，将实际图片登记到角色和造型；此处未假定已有图片。

## 4. 三个关联镜头

| 镜号 | 来源 | 剪辑时长 | 起点→主要动作→终点 | 摄影 |
|---|---|---|---|---|
| `EP001-S001` | P1 | 5秒 | 站在柜台后，双手未持物→低头看向钥匙→视线停在钥匙 | 中景，固定 |
| `EP001-S002` | P2 | 5秒 | 右手在钥匙旁→拾起钥匙→钥匙停在台面上方约5厘米 | 手部近景，固定 |
| `EP001-S003` | P3 | 5秒 | 右手仍握钥匙，视线向下→转头看向画左→目光停在画左 | 腰部以上中景，固定 |

`S002` 和 `S003` 改变构图，需要分别准备首帧；不直接把手部近景尾帧作为中景首帧。

### EP001-S001：发现钥匙

绑定计划：角色/造型图、场景图、钥匙参考用于制作首帧；普通 I2V 阶段输入实际选定首帧。

首帧提示词：

```text
9:16竖屏，二维电影感漫画，雨夜修表店内的固定中景。
黑色齐肩短发的成年女性修表师站在木柜台后，
穿米白衬衫与深棕工作围裙，低垂的目光尚未停在柜台物品上。
一把圆形钥匙头系短红线的旧铜钥匙平放在她面前的木台面上。
她的右手自然放在钥匙右侧约十五厘米处，左手放在柜台另一侧，双手没有持物。
后方是钟表架，右侧台灯投下稳定暖光，画面没有文字。
```

视频提示词 `v1`：

```text
镜头固定。修表师缓缓低头，将视线移向柜台上的铜钥匙，
目光在钥匙上停住，眉间轻微收紧。双手保持原位，钥匙留在台面上。
台灯光线和背景保持稳定。
```

验收：钥匙仍在台面，双手没有提前拿起钥匙，角色和服装未漂移。

### EP001-S002：拾起钥匙

绑定计划：钥匙参考、造型袖口参考、场景台面关系；首帧应以 `S001` 的实际可用结果核对。

首帧提示词：

```text
9:16竖屏，二维电影感漫画，木柜台台面的固定近景。
一把旧铜钥匙平放在画面中央，圆形钥匙头系着一根短红线。
米白衬衫袖口下的右手放在钥匙右侧约十五厘米处，
拇指和食指自然分开，尚未接触钥匙。
画面下缘只出现这只右手，背景上缘可见一小部分深棕工作围裙。
稳定的暖光从画面右侧照亮木纹、手指和钥匙，画面没有文字。
```

视频提示词 `v1`：

```text
镜头固定。右手缓慢靠近铜钥匙，拇指和食指捏住圆形钥匙头，
将整把钥匙平稳提起约五厘米后停住。短红线随钥匙离开台面，
自然垂下并轻微摆动。钥匙始终只有一把，保持完整的铜质外形。
```

验收：右手拾取、手指确实接触钥匙、道具没有复制或融化、红线随钥匙移动。拾取是较难动作，必须实际试拍。

### EP001-S003：转头

绑定计划：角色/造型、场景、钥匙；新首帧承接 `S002` 选定结果中的右手持物状态。

首帧提示词：

```text
9:16竖屏，二维电影感漫画，雨夜修表店内腰部以上中景。
同一位黑色齐肩短发的成年女性修表师站在木柜台后，
米白衬衫与深棕工作围裙保持一致，低头看着右手中的旧铜钥匙。
右手在木台面上方约五厘米处，用拇指和食指捏住钥匙头，
短红线自然垂下，左手仍放在柜台另一侧。
她的头尚未朝左转动。右侧暖台灯和后方钟表架保持原来的光影和布局。
```

视频提示词 `v1`：

```text
镜头固定。修表师保持右手拿着钥匙的姿势，
头部缓缓转向画面左侧，视线移向左侧画外并停住，
表情从专注变为警觉。身体和双手保持稳定，只有头部和目光发生变化。
```

后期备注：镜头开始时加入三下画外敲门声。本例未声明视频模型具备音频能力，敲门声不写入生产正文。

验收：人物向画左看；右手仍握钥匙；没有突然换衣、换手、移动到门口。

## 5. 一次假设返修：不是实测结果

**假设用户反馈**：`S002 v1` 在提起过程中钥匙融入手指，提供问题视频与对应时间点。

可以验证的假设：拾取接触过程超出了当前模型在此构图下的稳定能力。不能只凭现象确定根因，还要核对实际首帧、模型和输入。

备用方案：将“手指接触钥匙”的过程省略在剪辑点中。新首帧已经捏住钥匙头，视频只负责将钥匙提起。

| 项目 | 变化 |
|---|---|
| 剧本 | 仍为右手拿起钥匙，结果不变 |
| `S002` 起点 | 从“手未接触”改为“手已捏住钥匙头，钥匙仍贴台面” |
| `S002` 首帧 | 新版本，需要重新出图 |
| `S002` 视频词 | 新版本，只保留提起动作 |
| `S001` | 保留；到 S002 的切镜省略手靠近过程 |
| `S003` | 结束状态未改，仍需对照新结果检查持物位置 |

返修视频提示词 `v2`：

```text
镜头固定。右手保持捏住钥匙头的姿势，将铜钥匙从木台面缓慢提起约五厘米，
随后停住。短红线随钥匙提起并自然垂落，手指的握持方式保持不变，
钥匙的形状和长度保持稳定。
```

这次重做必须绑定新首帧；不能只替换视频文字却继续使用“手还未接触钥匙”的旧首帧。

下一次验证：接触是否稳定、钥匙是否完整、起点剪辑是否自然。结果未知，不能将 `v2` 标记成功配方。

## 6. 等待用户实际回填的内容

- 当前实际 ComfyUI 工作流、模型和输入槽。
- 选定的角色/造型图和三个首帧。
- 每镜实际提示词版本、参考输入、生成参数和结果。
- 采用/返修判定；若返修，提供问题时间点。

回填后才能计算可用率和生成次数，才能决定是否把这组配置保存为配方。
